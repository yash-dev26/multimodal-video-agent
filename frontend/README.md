# 🌟 Rocky AI — Blip-A Eridian Neural Interface

A multimodal alien-computer interface inspired by **Rocky** and ***Project Hail Mary***.

Recreated from the architectural and functional foundation of `kubrick-ui`, completely redesigned with a deep-space, xenonite-crystalline, and acoustic chord harmonic visual identity.

---

## 🚀 Key Features

* **Alien / Eridian Aesthetic**: Deep-space backgrounds, translucent xenonite glass cards, cyan/teal luminescent accents, and orbital particle trails.
* **Acoustic Harmonics & Chord Speech**: Rocky communicates in chord trills (`♫ [CHORD: D#4 · G4 · C5]`), echolocation sensor readouts, and iconic catchphrases (*"Amaze, amaze, amaze!"*, *"Fist my bump!"*, *"You sleep, I watch"*).
* **Multimodal Chat Interface**: Real-time conversation between **Dr. Ryland Grace** (*Hail Mary*) and **Rocky** (*Blip-A*).
* **Optical Sensor Attachment**: Attach microscope, telemetry, and celestial imagery with real-time preview and removal.
* **Video Telemetry Archive**: Upload sensor video feeds, real-time echolocation/astrophage processing progress visualizer, active sensor target tracking, and synchronized video playback.
* **Dual-Mode Backend Compatibility**: Compatible with the Kubrick Python backend API (`/chat`, `/upload-video`, `/process-video`, `/task-status/:id`), with rich in-character fallback synthesizer when testing standalone.

---

## 🛠️ Getting Started

Install dependencies:
```bash
npm install
```

Start the development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```
